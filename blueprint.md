# **App Name**: MathWhiz

## Core Features:

- Equation Input: Provide an input field for users to enter mathematical equations.
- Step-by-Step Solutions: Display detailed, step-by-step solutions for each entered equation, enhancing the learning experience.
- Basic Calculator: Offer a built-in calculator for quick calculations needed within the equation-solving process.
- History Tracking: Automatically save solved problems to view in the history. Make it easy to re-access past solutions.

## Style Guidelines:

- Primary color: A clean, educational green (#3CB371) to inspire trust.
- Background color: Off-white (#F5F5F5) for a clean and readable interface.
- Accent color: A slightly darker shade of green (#2E8B57) for interactive elements and highlights.
- Body and headline font: 'Inter' sans-serif font to ensure readability and a modern look, for both the equation input and solution displays.
- Use simple, clear icons to represent calculator functions and history navigation.
- Maintain a clean, intuitive layout with equations and solutions clearly separated for ease of understanding.
