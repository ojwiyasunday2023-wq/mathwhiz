# **App Name**: Equation Genius

## Core Features:

- Equation Input: Users can input mathematical equations using a text field or a virtual keypad.
- Equation Solving: An AI tool will parse and solve various types of mathematical equations, from basic arithmetic to advanced calculus.
- Solution Display: Display the step-by-step solution and final answer in a clear, well-formatted manner, including graphs where applicable.
- Solution History: Save a history of solved equations and their solutions for quick reference, stored locally.

## Style Guidelines:

- Primary color: A deep, professional blue (#3F51B5) for headers and interactive elements.
- Accent color: A vibrant, clear green (#4CAF50) for success indicators and call-to-actions.
- Background color: A light, neutral gray (#F5F5F5) to provide a clean canvas for mathematical content.
- Main text font: 'Roboto' (sans-serif) for general UI elements, ensuring readability.
- Equation font: 'Roboto Mono' or a similar monospaced font for displaying equations and solutions, maintaining clarity of mathematical symbols.
- Use sharp, geometric icons that clearly represent mathematical operations and app functions (e.g., plus, minus, equals, history).
- A split-pane layout for wider screens, with input on one side and solutions/history on the other; single-column on smaller devices.
- Subtle fades or slides when new solutions are displayed or history is accessed, providing a smooth user experience.
